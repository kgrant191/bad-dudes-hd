# Bad Dudes HD v1.0.0

The first complete release of Bad Dudes HD: a 4x graphics pack for Bad Dudes
(NES), built for MesenCE. All seven stages, both playable heroes, enemies,
bosses, effects, menus and ending screens are included.

## Highlights

- Detailed city, highway, sewer, forest, train, cave and factory environments.
- Moving vehicles and the final helicopter battle retain the game's geometry.
- Distinct hero artwork, weapons, palette changes and character-specific ending.
- Updated enemy and boss animations, including recoil and defeat states.
- Illustrated menus and ending scenes with live dialogue and credits.
- Consistent HUD and menu lettering, including game-over and scene fades.

## Install

Download **Bad_Dudes_HD_v1.0.0.zip**. In MesenCE, open your own
**Bad Dudes (USA).nes**, choose **Tools > HD Packs (NES) > Install HD Pack**,
and select the ZIP. Enable HD packs in NES settings and reload the game.

For manual installation, place the ZIP's contents in
`HdPacks/Bad Dudes (USA)/`. The folder name must match the ROM's base filename.

## Validation and presentation

Tested with MesenCE 2.2.1. The release preserves the approved v0.11.0 artwork
and runtime mappings. Regression evidence covers all seven stages as the
second character, the complete credits and subsequent menus, game over,
and a final cave replay. The source repository contains the detailed results.

Gameplay and music are unchanged. Native damage blinking, boss palette cycling,
sprite limits and clipping remain. Ending figures and flags are still
illustrations, while dialogue and scrolling credits are live.

No ROM, emulator or movie recording is included.
